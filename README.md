# SmartOS 智能操作系统原型 (LLM-Enhanced)

## 📖 项目简介
本项目是一个基于 C 语言开发的操作系统原型课程设计。有别于传统的控制台测试程序，本项目引入了 **SmartOS Shell**：一个深度集成了大语言模型（LLM）的智能控制台作为全系统的**唯一主入口**。

配合纯净的沙箱隔离、命令注入防御、进程并发死锁防控机制，实现了对 OS 核心概念（调度、内存、并发、文件系统）的现代化重构与模拟。它不仅仅是一个作业，更是一个健壮的终端系统探索。

## 🚀 核心特性
- **大引擎驱动：** 在 Shell 中输入 `@帮我找出最大的3个文件` 即可直接将自然语言通过 Python Bridge 转化为标准的 Linux 指令，并由安全沙箱（`sh -c`）隔离执行。
- **防止误杀护城河：** 拥有系统级别的中断抵抗力。在控制台中由于输入手误按下 `Ctrl + C` 时，SmartOS 能够完美截获底层 `SIGINT` 信号，使得守护主进程毫发无伤。
- **四大原生核心模块内置：** 
  - `run_scheduler`: 涵盖先来先服务(FCFS)、短作业优先(SJF)、时间片轮转(RR)。
  - `run_memory`: 提供 FIFO、LRU 页面置换；提供 FF、BF 动态分区防碎片模拟。
  - `run_concurrency`: 基于 `pthread` 和 `semaphore` 实现的生产者-消费者、读写竞态控制及完美的哲学家就餐防死锁模块。
  - `run_fs`: 二级文件系统目录模拟。
- **零内存泄漏规范：** 所有动态分配均可追踪，符合严苛的 Valgrind 标准。

## 🛠️ 环境依赖
- **操作系统**: Ubuntu (或其他主流 Linux 发行版)
- **编译链**: GCC & GNU Make
- **AI 扩展引擎后端**: Python 3.x, 以及接入 DeepSeek API / 本地端 [Ollama](https://ollama.com/) 驱动的 `qwen2.5` 等兼容模型。

## ⚙️ 编译与运行
项目中内置了极其精简的 GNU Makefile 来管理工程。不需要输入繁琐的 gcc 口令，两句话即可一键体验：

\`\`\`bash
# 清理旧有的构建产物并重新链接编译
make clean && make

# 启动 SmartOS 沙箱壳！
./build/os_simulation
\`\`\`

系统启动后，你将会看到 \`SmartOS >\` 的命令提示符。你可以像用原生 Linux 终端一样操作它，或者通过 \`@你要做什么\` 来唤醒系统内置大模型代理进程。
